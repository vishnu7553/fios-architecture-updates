# How to Use This Vault

Up: [[Home]]

> **Summary:** Working rules that keep the vault useful instead of becoming another chore.

The vault exists to reduce re-orientation cost. Every rule below serves that.

## Rules
1. **One NOW.** [[Now Next Later]] holds at most three NOW items, ideally one. Everything else is NEXT or LATER.
2. **Capture, do not act.** New ideas go into [[Parking Lot]] in one line. Triage them in the weekly review.
3. **Every note has an `Up:` link.** If you create a note, link it to a parent so the mind map stays connected.
4. **Decisions go in the Decision Log.** If you chose something and a future you might ask why, write an ADR using [[ADR Template]].
5. **Findings go in one place.** Model benchmarks go in [[Findings Log]], other research in [[Research]].
6. **End each session with [[Where Was I]].** Two minutes: last thing done, next tiny step, open loops.
7. **Small beats complete.** A note with three honest lines beats a perfect note you never write.

## Weekly review (15 minutes)
- Empty [[Parking Lot]]: delete, promote to NEXT, or file into a note.
- Update [[Now Next Later]].
- Check [[Open Questions]]: any answered? Move the answer into the relevant note.
- Check [[Roadmap]] status.

## Templates
Templates live in the `Templates/` folder. Enable the core Templates plugin in Obsidian (Settings, Core plugins). The folder is preconfigured. Available: [[ADR Template]], [[Milestone Template]], [[Research Note Template]], [[Daily Note Template]], [[Idea Capture Template]].

## Naming
Note names are unique across the vault so wiki links always resolve. Folders are numbered only to keep the sidebar in logical order.

## Map

- [[ADR Template]]: Template for a decision record.
- [[Milestone Template]]: Template for a roadmap milestone.
- [[Research Note Template]]: Template for a research note with provenance.
- [[Daily Note Template]]: Tiny daily check-in.
- [[Idea Capture Template]]: For an idea big enough for its own note.
